# 分基地预览

工厂卡片提供“列表、流程图、分图预览、数据”四个标签。原“流程图”显示完整方案。在“分图预览”点击“新建分基地”，填写名称、选择一个或多个中间产物作为最终产出，再点击“保存分基地”。选择和改名在保存前不生效，取消不会改变配置。

分基地从最终产出沿主链供料关系向上追溯，将上游加工配方及设备整体归入该基地。其余配方留在主基地。普通原料追溯不沿副产物回收支线扩张，避免清水、沉积酸的回收把赤铜、壤晶等无关生产拉入基地；明确选为最终产出的副产物仍正常追溯其生产配方。主基地及其他分基地通过“从仓库取用”接口获取已划出的加工材料，供料基地通过“送入仓库”接口输出。共用原料、共同产出的调度券不会将不同基地合并。一个基地可以生产多个中间产物，基地之间允许供料和回收依赖。

每个加工配方及其全部设备只归属一个基地；不拆分台数或另行求解。明确指定的最终产出配方优先保留给对应基地，再追溯上游。多个基地需要同一个上游配方，或同一配方同时产出两个基地选择的材料时，先创建的基地保留该配方。其余基地通过仓库取用；发生共同产出归属时显示提示。完全由其他基地的共同产出供应的基地可能没有独立设备。同一种最终产出不能重复指定给两个基地。

仓库接口只显示跨基地供料量。基地内部优先消化自己的产出，循环与本地加工保持直连；不足部分从仓库取用，供给其他基地的部分送入仓库。例如芽针与芽针种子的循环不经仓库，只有额外供给其他基地的芽针显示出口。清水、沉积酸等可直接开采的原料作为共享供给按基地取用量显示，不生成仓库接口，也不沿其回收支线扩张基地；无原料输入的开采设备仍在完整流程图和列表查看，分图不重复分配这些设备。本地回收产出保留在所在基地，原料供需仍由全局方案平衡。普通中间节点沿用完整流程图的合并规则，保留仓库端点。

点击仓库接口可查看全局供给、设备取用、目标产出、剩余产出和各基地的收发量，并跳转到对应基地。全局目标和剩余物料保留在主基地。以上是计算流量，不代表实时库存，也不增加仓库容量或吞吐量约束。

基地按钮切换主基地及分基地。当前分基地下方显示最终产出，可点击“编辑分基地”调整名称或产物；删除有确认提示，删除后生产重新归入主基地或其他基地。名称修改保留当前布局与缩放，改变产物或计算方案后重新布局。仅修改基地配置不会触发全局求解。

配置写入当前方案的 `fpt` 参数，随存档和分享链接恢复；切换工厂标签保留配置。旧版核心材料配置恢复为一个可编辑的分基地。没有分基地时显示完整主基地。分享链接仍不携带浏览器中的自定义配方库。

聚焦沿完整方案关系计算，再映射到当前基地及仓库接口。相关基地按钮带标记；隐藏未聚焦内容时，无关基地显示范围外提示。PNG 和 JSON 导出对应当前基地；完整流程在“流程图”标签导出。
