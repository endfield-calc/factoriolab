使用小技巧

区域计算限制：默认启用全区域。若只需计算特定区域，请在左侧 {{ 'settings.factory' | translate }} -> {{ 'settings.locations' | translate }} 调整勾选。
流程图显示：计算结果支持 {{ 'app.list' | translate }} 展示统计数据 或 {{ 'app.flow' | translate }} 展示工序。
发电量计算：点击按钮 {{ 'objectives.addMachines' | translate }} 选择发电设施（计算器中的发电量是用负数表示的）。
调度券计算： 可通过 {{ 'objectives.addItems' | translate }} 直接选择券； 或在 {{ 'objectives.addMachines' | translate }} 中选择产品兑换（设备数=产线数）。由于项目设计原因，最终产物兑换调度券也会显示需要传送带，无视即可。
避免超产：例如限制矿物产量，可通过 {{ 'objectives.addItems' | translate }} 选择矿物，并将 {{ 'options.objectiveType.output' | translate }} 更改为 {{ 'options.objectiveType.limit' | translate }}。
产线选择：使用 {{ 'objectives.addItems' | translate }} 添加的是输出目标产物，使用 {{ 'objectives.addMachines' | translate }} 添加的是要求指定数量的产线保持运行(会优先复用输出目标产物的必备产线)，
存档与重置：在左侧 {{ 'settings.savedStates' | translate }} 进行存取档。点击上方 游戏图标 可重置状态。
